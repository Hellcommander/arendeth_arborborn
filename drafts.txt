📁 Where to save it
Place the file here:

Code

🧪 What to name the file
Use the same ID as the JSON:

Code
building_vitriol_lab.json

🌿 How your zone should reference it
In your zone file (acid_magic_hall.json), set:

json
"building": "building_vitriol_lab"
This tells the engine:

spawn the custom building

use its rooms

use its props

use its doors

use its layout

Without this, the zone will load but no building will appear.
